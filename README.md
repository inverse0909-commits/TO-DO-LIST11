# TO DO LIST — Flutter

A modern dark-themed To Do List app based on the supplied reference design.

## Features
- Add, edit and delete tasks
- High/Low priority
- Due dates
- Complete/uncomplete tasks
- Task details
- Progress dashboard
- Statistics page
- Settings
- Local persistence using SharedPreferences
- Android-ready Flutter project

## Run
```bash
flutter pub get
flutter run
```

## Build APK
```bash
flutter build apk --release
```

APK output:
`build/app/outputs/flutter-apk/app-release.apk`
